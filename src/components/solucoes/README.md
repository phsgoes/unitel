# Soluções components

Reusable section components for marketing solution pages. Content is passed in from `src/data/solucoes/*` via `SolutionPageView.astro`.

| Component | Role |
| --- | --- |
| `SolutionPageView.astro` | Composes the full page from a `SolutionPage` |
| `SolutionHero.astro` | Hero + breadcrumb + CTAs + image |
| `ChallengeSection.astro` | Problem / challenge grid |
| `CompareSection.astro` | Before / after comparison |
| `BenefitsSection.astro` | Benefit cards (`#beneficios`) |
| `ResourcesSection.astro` | Sticky aside + feature grid |
| `ApplicationsSection.astro` | Optional use-cases (Call Center) |
| `PricingSection.astro` | Optional plans + comparison (ComuniQ) |
| `ProcessSteps.astro` | Numbered process |
| `RegionBanner.astro` | Regional CTA banner |
| `WhyUnitel.astro` | Differentiator cards |
| `ClientLogoGrid.astro` | Portfolio name grid |
| `FinalCta.astro` | Closing CTA + phone |
